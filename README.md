# Programming Quiz App 🧠💻

An interactive programming quiz web application built with **HTML, CSS, and JavaScript**.  
The quiz displays multiple-choice programming questions, calculates scores, gives performance feedback, and randomizes questions and options on every restart.

---

## 🚀 Live Demo
👉 https://princeonyerionwu16.github.io/interactive-quiz-app/


---

## 📌 Features
- Interactive multiple-choice quiz
- 15 programming-related questions
- Questions and answers shuffle on every restart
- Score tracking in real time
- Progress bar indicator
- Performance-based result message
- Fully responsive (works on mobile & desktop)

---

## 🛠️ Technologies Used
- HTML5
- CSS3
- JavaScript (DOM manipulation)

## 📖 How It Works
1. Click **Start Quiz**
2. Answer the questions
3. See your final score and feedback
4. Restart to get a new randomized quiz
